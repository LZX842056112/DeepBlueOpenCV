# 视频处理应用

一个基于Python、OpenCV和Gradio的视频处理应用，提供摄像头控制、视频录制和视频播放功能。

## 功能特性

### 🎥 摄像头控制
- 实时摄像头画面预览
- 支持多摄像头切换（索引0, 1, 2...）
- 自动调整摄像头参数（分辨率640x480，帧率30fps）
- 安全的资源释放机制

### 🎬 视频录制
- 实时视频录制功能
- 自定义文件名或自动生成带时间戳的文件名
- 支持AVI格式视频输出
- 录制状态实时显示

### 📹 视频播放
- 支持多种视频格式（MP4, AVI, MOV, MKV, WMV）
- 视频信息显示（分辨率、帧率、时长等）
- 视频画面预览
- 详细的视频元数据

## 安装要求

### 系统要求
- Windows 10/11, macOS, 或 Linux
- Python 3.7 或更高版本
- 可用的摄像头设备

### 依赖安装

```bash
pip install -r requirements.txt
```

或者手动安装：

```bash
pip install opencv-python==4.8.1.78
pip install gradio==4.12.0
pip install numpy==1.24.3
```

## 使用方法

### 快速开始

1. 克隆或下载项目文件
2. 安装依赖包
3. 运行应用：

```bash
# 运行基础版本
python video_app.py

# 运行改进版本（推荐）
python improved_video_app.py
```

4. 应用将在浏览器中自动打开，访问 `http://localhost:7860`

### 详细使用步骤

#### 1. 摄像头控制
- 在"📷 摄像头控制"标签页中
- 输入摄像头索引（通常0是默认摄像头）
- 点击"启动摄像头"开始预览
- 实时查看摄像头画面
- 使用"停止摄像头"释放资源

#### 2. 视频录制
- 确保摄像头已启动
- 切换到"🎬 视频录制"标签页
- 输入文件名（可选，留空自动生成）
- 点击"开始录制"开始录制
- 录制过程中可实时查看画面
- 点击"停止录制"结束录制

#### 3. 视频播放
- 在"📹 视频播放"标签页中
- 选择本地视频文件
- 点击"播放视频"查看信息和预览
- 查看视频的详细技术信息

## 技术架构

### 核心组件
- **OpenCV**: 视频捕获、处理和编码
- **Gradio**: Web界面和用户交互
- **Threading**: 多线程处理，确保界面流畅
- **NumPy**: 图像数据处理

### 主要类和方法

#### VideoProcessor (基础版本)
- `start_camera()`: 启动摄像头
- `get_frame()`: 获取摄像头帧
- `start_recording()`: 开始录制
- `stop_recording()`: 停止录制
- `read_video_file()`: 读取视频文件

#### ImprovedVideoProcessor (改进版本)
- 添加了线程安全的摄像头管理
- 实时帧更新机制
- 更好的错误处理
- 视频信息提取功能

## 故障排除

### 常见问题

1. **摄像头无法打开**
   - 检查摄像头索引是否正确
   - 确保摄像头没有被其他程序占用
   - 尝试不同的摄像头索引（0, 1, 2...）

2. **录制失败**
   - 确保摄像头已正确启动
   - 检查磁盘空间是否充足
   - 确认文件路径有写入权限

3. **视频播放问题**
   - 确认视频文件格式受支持
   - 检查视频文件是否损坏
   - 确保有足够的系统资源

### 错误代码说明

- **摄像头索引错误**: 尝试使用不同的索引号
- **文件权限错误**: 检查文件路径和权限设置
- **内存不足**: 关闭其他应用程序释放资源
