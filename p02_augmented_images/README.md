# 图片增强工具 - 深度学习数据增强

这是一个使用Python、OpenCV和Gradio构建的图片增强工具，专门用于深度学习模型训练时图片数量不足的情况。

## 功能特性

### 支持的图片增强方法
- **旋转**: 任意角度旋转图片
- **翻转**: 水平翻转、垂直翻转
- **亮度调整**: 调整图片亮度
- **对比度调整**: 调整图片对比度
- **高斯噪声**: 添加随机噪声
- **高斯模糊**: 模糊图片
- **锐化**: 增强图片细节
- **随机裁剪**: 随机裁剪并缩放回原尺寸
- **色调调整**: 调整图片色调
- **饱和度调整**: 调整图片饱和度
- **透视变换**: 模拟不同视角

| 增强类型        | 参数              | 默认值 | 效果       |
| --------------- | ----------------- | ------ | ---------- |
| rotate          | angle             | 30     | 旋转       |
| flip_horizontal | -                 | -      | 水平翻转   |
| flip_vertical   | -                 | -      | 垂直翻转   |
| brightness      | factor            | 1.5    | 亮度调整   |
| contrast        | factor            | 1.5    | 对比度调整 |
| gaussian_noise  | -                 | -      | 高斯噪声   |
| blur            | kernel_size       | 5      | 高斯模糊   |
| sharpen         | strength          | 1.0    | 锐化       |
| crop            | crop_ratio        | 0.8    | 随机裁剪   |
| hue_shift       | hue_shift         | 30     | 色调调整   |
| saturation      | saturation_factor | 1.5    | 饱和度调整 |
| perspective     | strength          | 0.5    | 透视变换   |



**随机参数范围说明（批量增强所有图片）**：

| 增强类型   | 参数       | 随机范围     | 效果            |
| ---------- | ---------- | ------------ | --------------- |
| **旋转**   | angle      | -180° ~ 180° | 任意角度旋转    |
| **亮度**   | factor     | 0.5 ~ 2.0    | 变暗到变亮      |
| **对比度** | factor     | 0.5 ~ 2.0    | 低对比到高对比  |
| **裁剪**   | crop_ratio | 0.7 ~ 0.95   | 裁剪70%-95%区域 |
| **色调**   | hue_shift  | -30 ~ 30     | 色调偏移        |
| **饱和度** | factor     | 0.5 ~ 2.0    | 低饱和到高饱和  |

### 界面功能

- **单张图片增强**: 选择单张图片并应用特定增强方法
- **批量增强**: 对所有图片批量应用增强，可指定每张图片生成数量
- **实时预览**: 增强前后图片对比显示
- **参数调节**: 针对不同增强方法提供可调节参数

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

1. 将需要增强的图片放入 `images` 文件夹
2. 运行程序：
```bash
python image_augmentation.py
```
3. 在浏览器中打开显示的URL（通常是 `http://127.0.0.1:7860`）
4. 选择增强模式：
   - **单张图片增强**: 选择图片和增强方法，调整参数后应用
   - **批量增强**: 选择增强方法和生成数量，一键批量处理

## 增强效果示例

- **旋转**: 模拟不同角度的拍摄
- **翻转**: 增加镜像对称样本
- **亮度/对比度**: 模拟不同光照条件
- **噪声/模糊**: 增加模型鲁棒性
- **裁剪**: 模拟不同构图
- **色调/饱和度**: 模拟不同色彩环境

## 注意事项

1. 支持的图片格式：JPG、JPEG、PNG、BMP
2. 增强后的图片保存在 `augmented_images` 目录
3. 文件名格式：`原文件名_增强类型.jpg`
4. 批量增强时会为每张图片生成多个随机参数的增强版本

## 技术栈

- **OpenCV**: 图片处理和增强算法
- **Gradio**: Web界面框架
- **NumPy**: 数值计算
- **Pillow**: 图片格式支持

## 适用场景

- 深度学习模型训练数据增强
- 计算机视觉项目数据准备
- 图像分类、目标检测、图像分割等任务
- 小样本学习的数据扩充
